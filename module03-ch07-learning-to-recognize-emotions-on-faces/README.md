# Facial Expression Recognition

A Python 3 implementation of real-time facial expression recognition using OpenCV Haar cascades for face detection, PCA for feature extraction, and a Multi-Layer Perceptron (MLP) neural network for classification. Built with wxPython for the GUI.

## Features

- **Real-time face detection** using Haar cascade classifiers
- **Face alignment** based on eye position detection
- **PCA (Principal Component Analysis)** for dimensionality reduction / feature extraction
- **MLP (Multi-Layer Perceptron)** neural network classifier
- **Two operating modes**:
  - **Training Mode**: Collect labeled facial expression samples via webcam
  - **Testing Mode**: Real-time facial expression recognition
- **6 expression classes**: Neutral, Happy, Sad, Surprised, Angry, Disgusted
- **Keyboard shortcuts**: ESC to exit, S to save screenshot
- **Auto-save**: Training data automatically saved on exit (no overwriting)

## Requirements

- Python 3.7+
- OpenCV (opencv-python) 4.x
- NumPy
- wxPython 4.x

## Installation

### 1. Install dependencies

```bash
pip install -r requirements.txt
```

Or manually:

```bash
pip install opencv-python numpy wxPython
```

### 2. Place Haar cascade files

Copy your Haar cascade XML files into the `params/` folder:

- `haarcascade_frontalface_default.xml`
- `haarcascade_lefteye_2splits.xml`
- `haarcascade_righteye_2splits.xml`

These files are typically included with OpenCV installations. You can also download them from the [OpenCV GitHub repository](https://github.com/opencv/opencv/tree/master/data/haarcascades).

## Usage

### Step 1: Collect Training Data

Run the main application in Training mode to collect facial expression samples:

```bash
python main.py
```

1. Select **Training** mode
2. Select an expression label (Neutral, Happy, Sad, etc.)
3. Position your face in front of the camera
4. Click **Take Snapshot** to capture a sample
5. Repeat for each expression class (aim for 20-50 samples per class)
6. Close the window (ESC or X button) — your samples will be saved automatically

**Tip**: Collect samples with varied lighting, head angles, and distances for better model generalization.

### Step 2: Train the MLP Classifier

Train the MLP on your collected data:

```bash
python train_test_mlp.py
```

This script will:
- Load your training samples from `datasets/faces_training.pkl`
- Perform PCA feature extraction (50 components by default)
- Split data into 80% training / 20% test sets
- Train 10 different MLP configurations with increasing hidden layer sizes
- Save the best-performing model to `params/mlp.xml`
- Save preprocessed data to `datasets/faces_preprocessed.pkl`

### Step 3: Real-time Expression Recognition

Run the main application again and switch to Testing mode:

```bash
python main.py
```

1. Select **Testing** mode
2. The system will detect your face and predict your expression in real-time
3. The predicted expression label is displayed above the face bounding box

## How It Works

### Face Detection
Uses OpenCV's Haar cascade classifiers to detect faces and eyes in each video frame. Detection is performed on a downscaled image for speed, then coordinates are scaled back up.

### Face Alignment
Detects left and right eyes within the face region. The face is then rotated and scaled so that:
- Both eyes lie on a horizontal line
- Eyes are positioned at 25% from the left/right edges
- Output size is standardized to 200×200 pixels

### Feature Extraction (PCA)
Principal Component Analysis reduces the dimensionality of the 200×200 = 40,000 pixel face image down to 50 principal components (eigenfaces). This dramatically reduces the input size for the classifier while retaining most of the variance.

### Classification (MLP)
A Multi-Layer Perceptron neural network with one hidden layer classifies the 50-dimensional PCA feature vector into one of 6 expression classes. The network uses sigmoid activation functions and is trained with backpropagation.

## Configuration

### Camera Index
The application uses camera index **1** (external webcam) by default. If no camera is found at index 1, it falls back to index 0.

To change the camera index, edit `main.py` and modify the `cv2.VideoCapture(1)` call in the `main()` function.

### PCA Components
Change the number of PCA components by editing the `num_components` parameter in `train_test_mlp.py`.

### MLP Architecture
The training script tests 10 hidden layer sizes automatically. To customize, modify the loop in `train_test_mlp.py`.

## Troubleshooting

### "Could not load face cascade"
Make sure all three Haar cascade XML files are in the `params/` folder with the correct filenames.

### "Empty data - cannot train"
You need to collect training samples first. Run `main.py` in Training mode and collect samples for each expression class.

### Camera not opening
- Check that your webcam is connected and not used by another application
- Try changing the camera index (0 or 1)
- On Linux, you may need to install `v4l2-ctl` or add your user to the `video` group

### wxPython installation issues
On some systems, wxPython may need system dependencies:
- **Ubuntu/Debian**: `sudo apt-get install python3-wxgtk4.0`
- **macOS**: `brew install wxpython`
- **Windows**: Use `pip install wxPython` (should work out of the box)

## File Naming Convention

- `faces_training.pkl` — Raw training samples (overwrite-protected on save)
- `faces_training-0.pkl`, `faces_training-1.pkl`, etc. — Auto-numbered if file exists
- `faces_preprocessed.pkl` — PCA-processed data with basis vectors
- `mlp.xml` — Trained MLP model
- `screenshot_YYYYMMDD_HHMMSS.png` — Screenshots saved on S key press
